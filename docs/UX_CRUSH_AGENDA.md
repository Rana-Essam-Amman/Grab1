# UX Crush Agenda — AI Box Refactor
العنوان الرئيسي: "الذكاء الاصطناعي يقترح، المستخدم يوافق، النظام ينفذ"

## 📌 المخطط الزمني والخطوات التنفيذية

### Phase 1: Discovery (اكتشاف البنية الحالية) — تم بنجاح ✅
- فهم هيكلية ومكونات صندوق المساعد الذكي `AiAssistantBox`
- مراجعة محدد النوايا `intentClassifier`
- تحليل شريط مدخلات الصور والصوت ومعالجة الكوتة

### Phase 2: Confidence Scoring (حساب نقاط الثقة)
- تعديل `intentClassifier.ts` ليقوم بإرجاع تفاصيل دقيقة تشمل:
  * تحديد النية الأساسية: `SEARCH` (بحث) أو `PUBLISH` (نشر إعلان)
  * حساب درجة الثقة (`confidence` من 0 إلى 1)
  * الكلمات المفتاحية المكتشفة التي ساهمت في اتخاذ القرار
- الحالات الخاصة:
  * إذا كانت درجة الثقة منخفضة (< 0.6) يتم تصنيف النية كـ `SEARCH` تلقائياً كحماية قصوى (Safe Default).

### Phase 3: Build AiPostSuggestion (إنشاء عنصر الاقتراح الذكي)
- تطوير مكون جديد مخصص يُعرض داخل الـ AI Box في حالة اكتشاف نية "النشر" بدرجة ثقة عالية.
- المكون سيوضح للمستخدم بلغة واضحة وجميلة (بالعربية والانجليزية):
  * "يبدو أنك ترغب في نشر إعلان لبيع [اسم السلعة] في قسم [القسم]!"
  * توفير زرين متاحين للتفاعل السريع: "انشر الآن" (لتأكيد النية) و "ابحث بدلاً من ذلك" (للتراجع أو التعديل).

### Phase 4: Wire Flow (ربط المسارات التفاعلية)
- تعديل معالج الإرسال في `useAiAssistant.ts` بحيث:
  * عند كتابة نص ذو نية نشر، لا يقوم النظام بالانتقال الفوري وتغيير الشاشات تلقائياً.
  * بدلاً من ذلك، يُعرض اقتراح النشر الذكي (`AiPostSuggestion`) للمستخدم ويحتفظ بحالة البحث المعروضة دون أي تشويش.
  * يتم تنفيذ عمليات البحث الاعتيادية في الخلفية كخيار افتراضي آمن لتجنب حدوث Backtrack للمستخدم.

### Phase 5: Post Wizard Pre-fill (تعبئة بيانات المعالج مسبقاً)
- عند ضغط المستخدم على زر "انشر الآن" التأكيدي من بطاقة الاقتراح:
  * يقوم النظام بالانتقال مباشرة إلى معالج النشر (`Post Wizard`).
  * يتم تعبئة كافة التفاصيل المستخرجة بواسطة الـ AI (العنوان، الوصف المقترح، السعر المقترح، القسم الرئيسي، القسم الفرعي، والصور المرفقة) مسبقاً في شاشات المراجعة مباشرة لتوفير الوقت والجهد بنسبة 100%.

### Phase 6: Tests + Verification
- التحقق التام من نجاح تشغيل جميع الـ 337 اختباراً دون حدوث أي خطأ أو تعليق في بنية النظام.
- مراجعة حجم البناء للتأكد من عدم وجود أي زيادة غير مرغوبة أو تداخلات برمجية.
